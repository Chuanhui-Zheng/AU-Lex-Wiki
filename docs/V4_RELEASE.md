# v0.4.0 release scope

V4 is complete when the repository, local database and release all agree on
the same boundary:

- six curated FWC decisions;
- 228 parsed decision chunks;
- 17 typed decision graph edges;
- 122 Awards, 121 Pay Guides, 30 FWO guidance records and 2 primary-law
  records retained from the earlier versions;
- zero stored vectors in the default text-only profile;
- measured V4 benchmark and refusal report;
- decision list/detail pages and direct Ask evidence links.

This release deliberately stops before bulk case-law ingestion and Enterprise
Agreement comparison. Those remain the V5 scope in the roadmap.
