# V3 acceptance checklist

- [ ] FWO guidance manifest validates with official authority labels;
- [ ] Workplace Guides, Fact Sheets and Best Practice Guides are represented;
- [ ] guidance evidence includes publisher and source URL;
- [ ] a casual-employment question can retrieve the matching FWO guide;
- [ ] an unrelated question still refuses;
- [ ] the text-only profile keeps all vector columns empty.

V3 is explanatory coverage, not a claim that FWO guidance replaces the Fair
Work Act, Regulations, Modern Awards or an approved agreement.
